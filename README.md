# 爱乐之城 · 表演道具验证器

## 启动

1. 双击或在 PowerShell 中运行 `start.ps1`。
2. 浏览器打开脚本输出的地址；默认是 `http://127.0.0.1:4173`。
3. 工具会自动读取 `data/爱乐之城-表演道具验证配置.xlsx`。

如果默认端口已占用，脚本会自动选择下一个可用端口。不要直接双击 `index.html`：浏览器的本地文件安全策略可能阻止自动读取工作簿。若必须直接打开，可以点击“加载配置表”手动选择工作簿。

## 道具图标

60 件道具均有独立本地图标。高分辨率源图位于 `assets/item-icons/source`，页面图位于 `assets/item-icons`，文件名与道具 ID 一致。替换单件源图后运行 `scripts/build-item-icons.mjs`，即可按配置中的占格比例重新导出。

## 修改配置

- `规则配置`：修改8×8背包、中央2×4初始区域、每3次表演扩1格、每次表演体力等参数。
- `品质配置`：修改品质顺序和界面颜色。
- `表演规则`：修改三段聚光、节拍判定、动画时长和事件概率。
- `发挥档位`：修改稳定、灵感、惊艳的权重与额外收益。
- `现场事件`：修改事件权重、分数影响、回应动作和减免比例。
- `种类表演特性`：修改六类道具的聚光权重与节拍窗口修正。
- `道具配置`：修改60件道具的分类、形状、限制、Lv.1—Lv.5数值、效果规则JSON和效果描述。

修改后保存为 `.xlsx`，刷新工具并点击“加载配置表”即可验证。效果计算使用“效果规则JSON”列；修改效果机制时应同时更新JSON和效果描述。

## 操作

- 默认进入“试玩模式”：初始随机获得1件紫色和1件蓝色道具，每3次表演随机解锁1件新道具；背包格也按每3次表演扩1格成长。
- “测试模式”保留60件全量道具、等级调整和复制测试，两种模式分别保存进度。
- 按住仓库或背包道具即可拖动。道具会跟随鼠标，背包中实时显示完整占格：绿色可放、橙色替换、红色无效。
- 新道具只覆盖一件旧道具且其余条件有效时，旧道具会自动回到仓库；无效落点松手后回原位。
- 背包道具可拖回仓库，也可使用“一键卸下”或 `Backspace`。
- `Ctrl+点击`背包道具可快速回仓库；`Ctrl+点击`仓库道具可自动寻找第一个完整空位。
- `Ctrl+Z` / `Ctrl+Y` 可以撤销或重做摆放。
- 每表演3次获得1次扩格；点击与现有可用格四向相邻的金色虚线格完成扩充。
- “解锁至”输入框支持直接把可用格调整到8—64中的指定数量，缩格后越界道具会返回仓库。
- 每场包含3段聚光表演，每段可点击一次节拍；现场事件出现时可按提示回应。支持正常速度、2倍速和跳过。
- 每次表演会记录基础分、发挥变化、操作变化、事件变化、最终得分、效率和复现种子，可导出CSV。
- “工具与配置”可按指定种子模拟1—1000场，不消耗体力也不改变仓库。
- 当前进度保存在浏览器本机；加载不同配置表时会建立对应的新测试进度。

## 数据说明

工具只计算背包内道具，仓库道具不参与表演得分。形状使用固定朝向，不提供旋转。测试模式默认拥有每种道具1件，可在详情中复制测试道具并调整等级。
