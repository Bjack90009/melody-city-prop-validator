# 道具图标生成基准

用途：浏览器游戏背包、仓库、奖励三选一与道具详情图标。

统一提示词：

> 活动 UE 风格的手游道具插画，手绘卡通写实，简化且略夸张的几何轮廓，柔和圆角，清晰色块与紧凑高光；古典欧洲剧院氛围，适量金色装饰。卡通化约 60%，材质写实约 40%。器物在 48px 下仍可辨认。深蓝黑色纯色背景 #07131c，无人物、界面、格子、文字、标识和水印。

构图按 `manifest.json` 的宽高确定：主体沿长边展开，占画布约 80%，四周保留约 12% 安全区。单件重绘时保持对应 `ID` 文件名，替换 `source/{ID}.png` 后运行 `../../scripts/build-item-icons.mjs`。
